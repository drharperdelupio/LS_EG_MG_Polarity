C101 Week 12 - Monday relay make-up page (self-grading, certificate at 80%)

index.html                  Student page. One self-contained file (no other files or internet needed).
                            Shows the Exam 3 note, the geometry reference sheet, six molecules,
                            checks answers (button turns on when every entry is filled), and
                            prints a certificate at 80% or higher.
instructor-answer-key.html  Instructor only. Do NOT publish with the student page.
                            (The student page also holds its answers in its source, so it
                            works on an honor basis.)
SHA256.txt                  Checksums of both files.

Place: copy the folder into your class-activity pages folder. Open index.html to use it.
To host it for students, publish index.html (for example with GitHub Pages) or upload it
to Canvas Files and link to it; Canvas pages strip scripts, so do not paste it into a page.
